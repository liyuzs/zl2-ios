# 从这里开始

> 这个文件夹里有 11 个文件。**先看下面这张表，别一个个翻。**

---

## 一、你只想装来玩（朋友）

按这个顺序，三步：

| 步骤 | 打开哪个 | 干什么 |
|---|---|---|
| 1 | **给朋友的安装指南.md** | 挑一条安装路线（TrollStore / SideStore / Sideloadly），照着做 |
| 2 | **ZL2.ipa** | 这就是 App 本体。用上一步选的工具装到手机上 |
| 3 | **真机验证清单-给朋友.md** | 装好之后照着走一遍，把结果告诉开发者 |

**出问题时最重要的一件事**：App 里有「打包日志分享」，点一下就能把现场发出去。
在清单的第十节有详细说明。**一个 zip 比十张截图有用。**

## 二、你要接着开发（接手者）

按这个顺序：

| 步骤 | 打开哪个 | 为什么 |
|---|---|---|
| 1 | **交接文档-当前.md** | 现状、改了什么、验证了什么、下一步。**开场读这一份就够** |
| 2 | **项目状态-当前.md** | 诚实版功能状态：哪些真能用、哪些只是"看起来能用" |
| 3 | **zl2-ios-完整仓库.bundle** | 全部提交历史。`git clone zl2-ios-完整仓库.bundle zl2-ios` 就能还原 |
| 4 | **脚本清单.md** | 72 个自检脚本的分类（哪个该跑、哪个已退役） |

代码也可以直接看 **zl2-ios-源码.zip**（只有源码，没有历史）。

## 三、你要把它推上 GitHub 重新构建

| 文件 | 用途 |
|---|---|
| **推送操作手册.md** | 手动推送的完整步骤（含 token 怎么生成、代理怎么配） |
| **推送并取回IPA.ps1** | 一条命令做完：推送 → 等 CI → 下载新 IPA → 校验体积 → 替换本文件夹里的旧 IPA |

```powershell
.\推送并取回IPA.ps1 -Token "github_pat_xxx"
```

> 脚本有保护：工作区不干净会停；下载到的 IPA 小于 100 MB 会失败且**不覆盖**旧包
> （小于 100 MB 说明 JRE 没打进去）。

## 五、两个提醒

1. **免费签名 7 天过期**：用 SideStore 可自动续签，用 Sideloadly 要手动重签。
   TrollStore（iOS 14–17.0）装一次永久可用。
2. **必须开 JIT**：不开的话帧率个位数。清单第三节有步骤。
