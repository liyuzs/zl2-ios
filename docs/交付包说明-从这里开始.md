## 一、你只想装来玩（朋友）

按这个顺序，三步：

| 步骤 | 打开哪个 | 干什么 |
|---|---|---|
| 1 | **给朋友的安装指南.md** | 挑一条安装路线（TrollStore / SideStore / Sideloadly），照着做 |
| 2 | **ZL2.ipa** | ⚠️ **这是 build-235 的旧包（11/8 构建）** —— 源码在那之后改了很多。要最新版请让开发者跑一次 `推送并取回IPA.ps1` 重新构建。先拿它试装可以，**但别当成最终版本** |
| 3 | **真机验证清单-给朋友.md** | 装好之后照着走一遍，把结果告诉开发者 |

**出问题时最重要的一件事**：App 里有「打包日志分享」，点一下就能把现场发出去。
在清单的第十节有详细说明。**一个 zip 比十张截图有用。**

### 这个 App 能做什么（装好之后你会发现）

| 能 | 说明 |
|---|---|
| **装原版 MC** | 支持 1.12 ~ 26+（1.11 及更早要 Java 8，包里只有 17/21/25，所以不支持）|
| **装 Fabric 加载器** | 装完就能加模组；同一个版本上再装一次 Fabric，之后启动就是模组版 |
| **换光影 / 资源包 / 模组** | 都是往版本目录里放文件，App 里有对应入口 |
| **管理存档** | 备份、恢复、导入导出 |
| **服务器列表 + 局域网发现** | 会自动发现同一 WiFi 下开的房间 |
| **导入控制布局** | 支持别人分享的 `.json` 布局文件；也能自己拖按钮位置 |
| **三种登录** | 微软正版 · 离线账号 · 外置认证（皮肤站）|
| **快捷指令 / Siri** | 「用 CraftLauncher 启动游戏」直接进 |
| **深色模式** | 跟随系统 |

**做不到的**（都由能力或平台限制，不是没做完）：
· **Forge / NeoForge** —— iOS 缺 JNA 组件
· **MC 1.11 及更早** —— 需要 Java 8
· **远程联机** —— 需要 Network Extension（付费开发者账号）
· **从别的 App 直接分享文件进来** —— 用「文件」App 拖进 CraftLauncher 的文件夹即可
· **外置认证只是离线身份** —— 皮肤会显示，但进不了需要正版验证的服务器

完整的能力边界与已知限制见 **项目状态-当前.md** 第六节。**那里写的是实话，不是免责声明。**

## 三、你要把它推上 GitHub 重新构建

| 文件 | 用途 |
|---|---|
| **推送操作手册.md** | 手动推送的完整步骤（含 token 怎么生成、代理怎么配） |
| **推送并取回IPA.ps1** | 一条命令做完：推送 → 等 CI → 下载新 IPA → 校验体积 → 替换本文件夹里的旧 IPA |

```powershell
.\推送并取回IPA.ps1 -Token "github_pat_xxx"
```

> 脚本有保护：工作区不干净会停；下载到的 IPA 小于 100 MB 会失败且**不覆盖**旧包
> （小于 100 MB 说明 JRE 没打进去）。
