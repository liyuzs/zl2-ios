# ZL2-iOS 装机测试指南

> 2026-11-06 编写。项目已通过 Codemagic 编译，产出未签名 IPA。
> 本文只写「怎么做」，遇到报错把日志发出来即可。

---

## 一、你要准备什么

| 东西 | 说明 |
|---|---|
| **一台电脑**（Windows 或 Mac） | 只需要用一次，给手机装签名工具 |
| **iPhone 数据线** | 连接手机和电脑 |
| **Apple ID** | 免费账号即可，不用开发者账号 |
| **IPA 文件** | 从 Codemagic 的 Artifacts 下载 `ZL2.ipa` |

---

## 二、装 App（两条路，选一条）

### 路线 A：NB 全能助手（推荐，中文界面）

1. 电脑上打开浏览器，搜「NB 全能助手」，从官网下载
2. 安装到电脑，打开
3. 数据线连手机，手机上点「信任此电脑」
4. 软件里选「IPA 签名」→ 导入 `ZL2.ipa`
5. 输入你的 Apple ID（免费账号就行）
6. 点签名，等 1～3 分钟
7. 签名完成后点「安装到设备」

**装完在手机上会看到一个图标。**

### 路线 B：Sideloadly（英文，但更稳）

1. 电脑上访问 `sideloadly.io`，下载安装
2. 连手机，把 `ZL2.ipa` 拖进 Sideloadly 窗口
3. Apple ID 填进去
4. 点 Start，等进度条走完

---

## 三、第一次打开会怎样

### 3.1 可能会被拦截

如果提示「不受信任的开发者」：

```
设置 → 通用 → VPN与设备管理 → 点你的 Apple ID → 信任
```

### 3.2 应该看到什么

1. **启动页**：深色背景 + 毛玻璃卡片，显示自检进度
2. **主页**：顶部有图标，中间是版本卡片
3. **侧栏**：点左上角能划出导航

### 3.3 如果闪退

**这是最可能的情况**。原因通常是：

| 原因 | 表现 |
|---|---|
| 核心库没打进包 | 一打开就闪退 |
| JRE 没下载 | 能进界面，点启动后闪退 |
| 缺 JIT 权限 | 能下载 JRE，启动游戏时崩 |

**闪退的话**：手机连电脑，用 Xcode 或 Console 看崩溃日志，或者告诉我「第几步闪退」。

## 四、下载 JRE（关键一步）

进 App 后：

1. 侧栏 → **Java 管理**
2. 会看到 Java 8 / 17 / 21 / 25
3. 点「下载」（每个约 80～120 MB）
4. **至少下一个 Java 17**（大部分新版 MC 要 17+）
5. 玩 1.16.5 及更老版本需要 Java 8

**下载源**：`assets.angelauramc.dev`，国内可能慢，耐心等或挂梯子。

---

## 五、装一个游戏版本

1. 主页 → 点「下载」图标 或 侧栏 → 下载
2. 选版本（推荐先试 **1.20.1**）
3. 选加载器（**Fabric** 最稳）
4. 点安装，等进度
5. 装完在「版本管理」里能看到

---

## 六、启动游戏（真正的考验）

1. 主页选中刚装的版本
2. 点「启动游戏」
3. **观察启动日志**（启动页会滚动显示）

### 预期的几个阶段

```
✓ 检查 Java 运行时
✓ 检查版本文件
✓ 解压 natives
✓ 启动 JVM
  ...
  游戏窗口出现
```

**卡在哪一步，就把那一步的日志发出来。**

---

## 七、JIT 问题（如果启动 JVM 时崩溃）

iOS 默认禁止 App 动态生成代码，跑 Java 必须要 JIT。

### 方案：StikDebug

1. 手机上装 **StikDebug**（从 `github.com/StikDebug/StikDebug` 下载 ipa，同上面方式签名安装）
2. **第一次需要电脑**：用电脑导出配对文件（`.mobiledevicepairing`）
3. 把配对文件传到手机 StikDebug 里
4. 之后打开 StikDebug → 选 ZL2 → 点「Enable JIT」

**iOS 26 支持**，但注意官方标注「Limited App Availability」——有些 App 需要开发者适配。

**好消息**：我们的核心代码里已经有 `UniversalJIT26` 脚本，说明核心自己知道怎么用 JIT。

## 八、卡住时怎么反馈

**给我这三样，我就能定位**：

1. **第几步出的问题**（装不上 / 闪退 / JRE 下载失败 / 启动卡住）
2. **报错文字**（截图存到手机 `/sdcard/Download/`，告诉我文件名，我能直接读）
3. **如果是启动失败**：启动页上的日志内容

**不用给我全部，只要带 `error` 或 `Exception` 的那几行。**

## 九、已知的坑（我提前说）

| 坑 | 说明 |
|---|---|
| **免费签名 7 天过期** | 到期 App 打不开，要重新签名 |
| **JRE 下载慢** | 国外源，可以挂梯子 |
| **首次启动要下资源** | MC 本体资源约 200MB，第一次启动会下载 |
| **JIT 没开就是跑不起来** | 这不是 bug，是 iOS 限制 |
| **游戏内菜单可能没有入口** | 已知问题：核心的 `launchJVM` 不创建 UIViewController，SwiftUI 层挂不上悬浮层。游戏能玩但可能没有 FPS 球 |

---

## 十、装好之后

如果游戏能进主菜单：

1. **先别急着装模组**，确认原版能跑
2. 能跑之后再试 Fabric API + 一两个小模组
3. 联机功能需要 EasyTier 内核，目前还没接入（界面上会显示"未接入"）
