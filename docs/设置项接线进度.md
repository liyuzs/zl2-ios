## 二、本轮接线的 7 项

### 1. 编辑器吸附三项

| 设置项 | 效果 |
|---|---|
| `editorEnableWidgetSnap` | 总开关，关掉后不吸附 |
| `editorSnapInAllLayers` | 开启后可以吸附到其它图层的控件 |
| `editorWidgetSnapMode` | `FullScreen`（容差 3%）/ `Local`（容差 1.2%） |

**实现位置**：`ControlEditor.applySnap(_:current:)`

原来的吸附只是简单的 50 分格取整：

```swift
newX = (newX * 50).rounded() / 50
```

现在改成**真正的边缘吸附**——拖动时找最近的参考线：

```swift
let candX = [
    t.x - (t.width + current.width) / 2,   // 贴左边
    t.x,                                    // 中心对齐
    t.x + (t.width + current.width) / 2     // 贴右边
]
```

如果附近没有可吸附的控件，退回分格对齐。手感：拖到另一个按钮旁边会自动对齐边缘，不用手动微调。

### 2. `currentAccount`

账号系统选中的账号，同步到 ZL2 的设置键。

**实现位置**：`AccountStore.persist()`

```swift
if let account = current {
    defaults.set(account.username, forKey: Keys.legacyName)
    defaults.set(account.type.rawValue, forKey: Keys.legacyType)
    defaults.set(account.uuid, forKey: "currentAccount")   // ← 新增
}
```

### 3. `currentGamePathId`

当前游戏实例名，切换实例时同步。

**实现位置**：`GameDirectoryStore.activate(_:)`

```swift
defaults.set(name, forKey: "zl.game.instance")
defaults.set(name, forKey: "currentGamePathId")   // ← 新增
```

### 4. `finishedGame`

累计启动次数。

**实现位置**：`CoreBridge.recordGameLaunch()`

```swift
let count = d.integer(forKey: "finishedGame") + 1
d.set(count, forKey: "finishedGame")
if d.object(forKey: "firstLaunchDate") == nil {
    d.set(Date(), forKey: "firstLaunchDate")
}
d.set(Date(), forKey: "lastLaunchDate")
```

挂在两条启动路径的成功分支上（`launchVersion` 和 `launchJar`），启动失败不计数。

顺带存了 `firstLaunchDate` / `lastLaunchDate`，以后做使用统计用得上。

## 三、剩下 3 项为什么不接

全部是 Terracotta 联机相关：

| 设置项 | 阻塞原因 |
|---|---|
| `enableTerracotta` | 需要 Network Extension（付费开发者账号 + 苹果审核） |
| `enableTerracottaNodes` | 同上 |
| `terracottaNodes` | 同上 |

Terracotta 是 P2P 联机方案，iOS 上必须走 Network Extension 才能建立本地网络通道。
当前账号是免费签名，装不了带 NE 的 App。

**这不是「没写」，是「平台限制」**，已在设置页标注「尚未接入，暂时无效」。
