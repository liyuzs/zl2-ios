## 六、文档维护约定

1. **技术改造必须留文档** —— 每轮改了什么、为什么这么改、怎么验证的
2. **给用户看的和给开发者看的分开** —— 用户文档不要出现代码路径
3. **状态要诚实** —— 没验证过就写「没验证过」，别写「应该可以」
4. **过时的不删，标废弃** —— 历史记录有价值，但要在索引里标明
