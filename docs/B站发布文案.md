## 简介（直接复制）

```
这是一个非官方的 iOS 移植版 Minecraft Java 版启动器。

基于 Zalith Launcher 2（安卓）重写界面，启动核心用 Amethyst。
支持 1.8 ~ 26+ 版本、Fabric/Quilt 模组、光影、局域网联机。

⚠️ 声明：
本软件是社区非官方修改版，与 Zalith Launcher 官方无关。
界面代码为原创重写，感谢原项目作者 MovTery 与 Angel Aura MC。

📦 下载与装法见置顶评论 / 简介末尾
💬 有问题评论区问，我会回

#我的世界 #Minecraft #iOS #Java版 #启动器
```

## 置顶评论

```
【怎么装】
免费，7 天续签，不用开发者账号

1. 电脑下载 IPA（GitHub 链接放这）
2. 用「NB 全能助手」或「iLoader」签名安装
3. 手机设置里信任证书
4. 装 StikDebug，给 App 开 JIT（必须！否则会很卡）
5. 开玩

【配置要求】
iPhone 11 及以上比较流畅
iOS 16 或更高

【已知问题】
· Forge/NeoForge 装不了（要用电脑跑 installer.jar）
· 远程联机还在做
· 原版 1.20 大概 25-40 帧
```
