## 二、阶段一：电脑上操作（约 20 分钟，只做一次）

### 步骤 1：装 iTunes
- 从 **Microsoft Store** 装「iTunes」（不要从苹果官网下 EXE 版，商店版才带驱动）
- 装完打开一次，确认能识别手机

### 步骤 2：下载 iLoader
- 官网：https://iloader.app/ （或从 GitHub Releases）
- 这是替代 AltServer 的新工具

### 步骤 3：连接手机，生成配对文件
1. 数据线连接 iPhone 14 和电脑
2. 手机上点「信任此电脑」，输入锁屏密码
3. 打开 iLoader → 找到 **Manage Pairing File**
4. 点 **Place** 按钮生成配对文件

> ⚠️ **配对文件是这台设备 + 这个 iOS 版本的凭证，系统升级后要重新生成**

### 步骤 4：用 iLoader 装 SideStore
1. iLoader 里找到 SideStore 安装选项
2. 输入你的 Apple ID（**建议用备用 ID，不要用主账号**）
3. 等待安装完成
4. 手机上：设置 → 通用 → VPN与设备管理 → 信任开发者

## 三、阶段二：手机上操作（约 15 分钟）

### 步骤 5：装 LocalDevVPN
1. 用**美区 Apple ID** 登录 App Store
2. 搜索 **LocalDevVPN** 并安装
3. 打开它，点 **Connect**
   - 它会创建一个本地 VPN，用来模拟「和电脑连着」

> 💡 没有美区 ID？注册方法：App Store 退出当前账号 → 随便点个免费 App 登录 → 选「创建新 Apple ID」→ 地区选美国 → 地址随便填个美国地址（如 Beverly Hills 90210）

### 步骤 6：初始化 SideStore
1. 打开 SideStore，登录**同一个 Apple ID**
2. 进入 **My Apps**
3. 点 SideStore 旁边的 **7 DAYS** 数字
4. 等它刷新完成

### 步骤 7：装 ZL2
1. 把 `ZL2.ipa` 传到手机（微信文件传输 / 网盘 / 数据线都行）
2. SideStore → My Apps → 右上角 **+** → 选择 ZL2.ipa
3. 等待安装（52MB，可能要几分钟）

> ⚠️ **这一步最容易失败**，原因见下面「常见问题」

### 步骤 8：装 StikDebug 并开 JIT
1. 在 SideStore 里安装 **StikDebug**（官网 https://stikdebug.xyz/ 有 IPA）
2. 或者用 SideStore 添加源直接搜
3. 打开 StikDebug → 找到 ZL2 → 点 **Enable JIT**
4. 看到成功提示

### 步骤 9：启动 ZL2
1. 打开 ZL2
2. 首次会显示引导（首页 + 控制编辑器）
3. 到「下载」页，选一个版本点下载
4. 下载完成后回首页点「启动游戏」

## 四、常见问题与解决

### ❌ SideStore 安装 IPA 报错「missing bundle executable」
**原因**：IPA 不完整或签名失败
**解决**：重新下载 IPA，确认文件大小是 52MB 左右

### ❌ App 打开闪退
**原因**：50 个 dylib 里有些没有被正确签名
**解决**：
1. SideStore 里长按 ZL2 → Refresh
2. 还不行的话，用 Sideloadly 在电脑上签一次（它会递归签所有 dylib）

### ❌ JIT 开不起来
**原因**：iOS 26.5 上 StikDebug 还在适配
**解决**：
1. 确认 LocalDevVPN 是 **Connected** 状态
2. 确认配对文件是最新的
3. 重启 StikDebug 再试

### ❌ 启动游戏卡住 / 黑屏
**原因**：JIT 没生效，或者资源文件没下载完
**解决**：先确认 JIT 已开（StikDebug 里能看到状态），再重新下载版本

### ❌ 7 天后 App 打不开了
**原因**：免费签名过期
**解决**：打开 SideStore → Refresh All（需要 LocalDevVPN 连着）
