## 六、第三轮：控制模块专项（2026-11-04 00:41 录屏，86秒）

### 1. 控制管理页（设置 → 控制设置 → 控制管理）⚠️ 独立页面

**布局**：
- 左侧：工具栏（刷新 / 导入 / 创建）+ 布局列表
  - 每个布局：单选圆圈 + 名称（默认、我）+ 版本（1.0）+ 手机图标 + 删除
- 右侧：布局信息面板
  - 布局名称、布局创作者（墨北MovTery）、布局版本、布局描述
  - 底部两按钮：**分享** / **编辑控制布局**

### 2. 创建新布局弹窗

- 布局名称（**必填**，空时报"该项不能为空"）
- 布局创作者
- 文本字数计数（0/128）
- 布局版本
- 取消 / 创建

### 3. 控制编辑器真机形态 ⚠️ 比我做的复杂

**画布上的预设控件**（截图里看到的）：
- 键盘类：`ESC` `F3` `F5` `Tab` `Ctrl` `Alt` `输入法`
- 方向类：`滑动↑` `滑动↓`
- 压力/动作类：`左键` `右键`

**左侧抽屉菜单**：
- 添加按钮
- 添加文本框
- **控件外观列表**
- **摇杆样式**

**右侧控件层列表**：`gui` `tab` 等，每个带设置/删除，底部「新建」

**控件属性面板**：
- 基本信息：应用圆角 / 启用斜体 / 启用下划线
- 文本：编辑文本
- 事件：点击事件 / 控件样式
- 底部：开启预览 / 删除 / 复制控件 / 关闭

**控件外观列表弹窗**（独立）：
- 外观项：`topend` / `toptart` / `bottomend` …
- 每项：设置 / 删除 / 应用
- 底部：创建 / 关闭

### 4. 控制设置真机项

| 项 | 说明 |
|---|---|
| 实体键盘呼出输入法 | 点击绑定一个按键（未绑定） |
| 虚拟鼠标指针（默认） | 自定义图片 → **设置热点** |
| 虚拟鼠标指针（手形） | MC 1.21.9+ → 设置热点 |
| **虚拟鼠标指针（输入光标）** | MC 1.21.9+ 输入框用 → 设置热点 |

> 我之前只有"输入法模式"一项，缺指针三态和热点配置。
