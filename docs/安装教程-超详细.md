# CraftLauncher 安装教程（超详细版）

> 全程免费 · 不需要开发者账号 · 只需要一台电脑用一次
> 预计耗时：15 分钟

---

## 你要准备什么

| 需要 | 说明 |
|---|---|
| 📱 iPhone / iPad | iOS 16 或更高 |
| 💻 电脑 | Windows 10+ 或 Mac，**只需要用一次** |
| 🔌 数据线 | 能连 iPhone 的 |
| 🆔 Apple ID | 免费账号就行，不用开发者账号 |
| 🌐 网络 | 电脑和手机都要能上网 |

---

## 第一步：装 SideStore（电脑操作）

SideStore 是一个「应用商店」，装好之后你就能像装普通 App 一样装 CraftLauncher。

### Windows 用户

1. 先装 **iTunes**
   - 微软商店搜「iTunes」安装
   - 或者去苹果官网下载

2. 用数据线把 iPhone 连到电脑
   - 手机上会弹出「要信任此电脑吗」→ 点**信任**
   - 输入手机密码

3. 下载 **iLoader**
   - 打开 https://github.com/SideStore/iLoader/releases
   - 下载 `iLoader-Windows.zip`
   - 解压后运行 `iLoader.exe`

4. 在 iLoader 里点 **Install SideStore**
   - 它会在你的手机上装上 SideStore
   - 过程中可能要输入你的 Apple ID（**只用于签名，不会上传**）

### Mac 用户

1. 打开「终端」，粘贴这行回车（装 Xcode 命令行工具）：

```bash
xcode-select --install
```

2. 用数据线连 iPhone，点「信任」

3. 下载 **iLoader**
   - https://github.com/SideStore/iLoader/releases
   - 下载 macOS 版，拖进「应用程序」

4. 打开 iLoader，点 **Install SideStore**

---

## 第二步：手机上信任证书

1. 打开 **设置** → **通用** → **VPN与设备管理**
2. 找到你的 Apple ID（或者「开发者 App」）
3. 点进去 → 点 **信任**

> 如果不信任，App 打不开，会提示「未受信任的开发者」。

---

## 第三步：添加源（关键）

1. 打开手机上的 **SideStore**
2. 用**同一个 Apple ID** 登录
3. 点底部 **Sources**（源）
4. 点右上角 **+** → **Add Source**
5. 粘贴这个地址：

```
https://liyuzs.github.io/zl2-ios/source/apps.json
```

6. 点 **Add**

---

## 第四步：安装 CraftLauncher

1. 在 SideStore 的 **Browse** 页面找到 **CraftLauncher**
2. 点 **FREE** → **INSTALL**
3. 等它下载、签名、安装（大概 2-5 分钟）

---

## 第五步：开启 JIT（必须！）

**不开 JIT，游戏会卡到没法玩。**

1. 打开 **StikDebug**（App Store 搜不到，需要单独装）
   - 下载地址：https://github.com/StikDebug/StikDebug/releases
   - 用同样的方法签名安装

2. 打开 StikDebug，找到 **CraftLauncher**
3. 点 **Enable JIT**
4. 从 StikDebug 里启动 CraftLauncher

> 每次启动游戏前都要从这里进。

---

## 第六步：开始玩

1. 打开 CraftLauncher
2. 点右上角下载图标 → 选一个版本（建议先试 1.20.1 原版）
3. 等下载完
4. 回首页 → 点「启动游戏」
5. 第一次启动会慢（几分钟），耐心等

## 常见问题

### Q: 提示「无法验证 App」
A: 回到第二步，重新信任证书。

### Q: App 打不开了，说过期了
A: 免费签名 7 天过期。打开 SideStore，点 **Refresh All** 续签。**数据不会丢**。

### Q: 游戏卡 / 闪退
A: 检查是不是忘了开 JIT（第五步）。另外可以在设置里把视距调到 4。

### Q: Forge 装不了
A: iOS 上装不了 Forge（需要跑 installer.jar）。用 **Fabric** 或 **Quilt**。

### Q: 能不能和朋友联机
A: **同一个 WiFi** 下可以。你在游戏里「对局域网开放」，对方在多人游戏里就能看到。

### Q: 会不会封号
A: 不会。用的是你自己的 Apple ID 签名，跟 App Store 下载没区别。

### Q: 会不会有病毒
A: 代码全部开源：https://github.com/liyuzs/zl2-ios
