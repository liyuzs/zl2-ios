# 电脑端操作指令（给电脑上的 AI / 自动化用）

> 目标：在 Windows 上完成 iLoader + SideStore 的首次部署，装好 ZL2
> 最后更新：2026-11-03
> 说明：本文件是**指令清单**，不是教程。命令可直接复制执行。

---

## 前置条件

| 条件 | 检查方式 |
|---|---|
| Windows 10/11 x64 | `Get-ComputerInfo \| Select OsName, OsVersion` |
| 有管理员权限 | PowerShell 以管理员运行 |
| iPhone 用数据线连接 | `Get-PnpDevice -Class USB \| Where FriendlyName -like "*Apple*"` |
| 网络能访问 GitHub | `Invoke-WebRequest https://github.com -Method Head` |

---

## 步骤 1：安装 iTunes（提供 usbmuxd 驱动）

```powershell
winget install --id Apple.iTunes -e --accept-package-agreements --accept-source-agreements
```

装完**打开一次 iTunes**，确认能看到设备。

验证驱动：
```powershell
Get-PnpDevice -FriendlyName "*Apple*" | Select Status, FriendlyName
```

---

## 步骤 2：下载并安装 iLoader

官方仓库：https://github.com/nab138/iloader

```powershell
$url = "https://github.com/nab138/iloader/releases/latest/download/iloader-windows-x64.msi"
Invoke-WebRequest -Uri $url -OutFile "$env:TEMP\iloader.msi"

# 安装（静默）
Start-Process msiexec.exe -ArgumentList "/i `"$env:TEMP\iloader.msi`" /qb" -Wait

# 或便携版：
# Invoke-WebRequest "https://github.com/nab138/iloader/releases/latest/download/iloader-windows-x64.exe" -OutFile "$env:USERPROFILE\iloader.exe"
```

## 步骤 3：下载 ZL2.ipa

### 方式 A：用 gh CLI（需要 GitHub token）

```powershell
# 装 gh
winget install --id GitHub.cli -e --accept-package-agreements

# 登录（会弹浏览器）
gh auth login

# 下载最新构建产物
gh run list --repo liyuzs/zl2-ios --workflow "iOS Build" --limit 1
$runId = (gh run list --repo liyuzs/zl2-ios --workflow "iOS Build" --json databaseId --jq '.[0].databaseId')
gh run download $runId --repo liyuzs/zl2-ios -n ZL2-build -D "$env:USERPROFILE\zl2"
Expand-Archive "$env:USERPROFILE\zl2\ZL2-build.zip" -DestinationPath "$env:USERPROFILE\zl2" -Force
Get-ChildItem "$env:USERPROFILE\zl2" -Filter *.ipa
```

### 方式 B：网页手动下载

1. 打开 https://github.com/liyuzs/zl2-ios/actions
2. 点最新一次 **iOS Build**（绿色勾）
3. 页面底部 **Artifacts** → 点 `ZL2-build`
4. 解压得到 `ZL2.ipa`（约 52 MB）

---

## 步骤 4：连接手机，生成配对文件（GUI 操作）

**以下必须人工/操作 GUI，无法纯命令**

1. 数据线连接 iPhone 14
2. 手机上点「信任此电脑」→ 输入锁屏密码
3. 启动 iLoader
4. 左侧找到 **Manage Pairing File** 或 **Pairing**
5. 点 **Place** / **Generate**
6. 确认提示成功

验证配对文件位置：
```powershell
Get-ChildItem "$env:APPDATA\iloader","$env:LOCALAPPDATA\iloader" -Recurse -Filter "*pairing*" -ErrorAction SilentlyContinue
```

---

## 步骤 5：用 iLoader 装 SideStore（GUI 操作）

1. iLoader 界面里找 **Install SideStore**
2. 输入 Apple ID（**用备用账号**）
3. 输入密码（会走苹果官方登录，iLoader 不存储）
4. 等待安装完成
5. 手机上：设置 → 通用 → VPN与设备管理 → 信任该开发者

---

## 步骤 6：手机上装 LocalDevVPN

1. App Store 切到**美区账号**
2. 搜 **LocalDevVPN** → 安装 → 打开 → 点 **Connect**

> 无美区 ID 时：App Store 退出当前账号 → 随便点个免费 App → 创建新 Apple ID → 地区选 United States → 地址填任意美国地址

---

## 步骤 7：手机上装 ZL2

1. SideStore → 登录同一 Apple ID
2. **My Apps** → 点 SideStore 旁边的 **7 DAYS** 完成初始化
3. 右上角 **+** → 选择 `ZL2.ipa`
4. 等待安装（52MB）

---

## 步骤 8：装 StikDebug 并开 JIT

1. 官网 https://stikdebug.xyz/ 下载 IPA
2. 用 SideStore 装进去
3. 打开 StikDebug → 找到 ZL2 → **Enable JIT**
4. 确认显示成功

---

## 步骤 9：验证

手机上：
1. 打开 ZL2
2. 看到引导页 → 完成
3. 下载页选版本 → 下载
4. 首页 → 启动游戏

## 排错命令

### 检查设备连接
```powershell
# iTunes 是否识别设备
& "C:\Program Files\iTunes\iTunes.exe" /?
# 或用 Apple Mobile Device 服务
Get-Service "Apple Mobile Device Service" | Select Status
Start-Service "Apple Mobile Device Service" -ErrorAction SilentlyContinue
```

### 检查 IPA 完整性
```powershell
$ipa = "$env:USERPROFILE\zl2\ZL2.ipa"
(Get-Item $ipa).Length / 1MB   # 应约 52
Add-Type -AssemblyName System.IO.Compression.FileSystem
$z = [System.IO.Compression.ZipFile]::OpenRead($ipa)
$z.Entries.Count                # 应约 350+
$z.Entries | Where-Object { $_.FullName -like "*/Frameworks/*.dylib" } | Measure-Object  # 应约 50
$z.Dispose()
```

### 配对文件生成失败
- 确认 iTunes 版本来自 Microsoft Store
- 换 USB 口（直连主板，不要用 hub）
- 重启 `Apple Mobile Device Service`
- 备选工具：`idevice_pair`（https://onmyodev.com/2026/10/idevice-pair/）

## 已知风险

| 风险 | 说明 |
|---|---|
| iOS 26.5 的 StikDebug 未实测 | 官方只写到 26.0+ |
| SideStore 重签名 50 个 dylib 可能失败 | 失败时改用 Sideloadly 递归签名 |
| 免费证书 7 天 | 之后要 Refresh All |
| 我们的 App 从未真机运行 | 首次可能崩溃，属正常 |
