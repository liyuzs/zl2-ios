## 七、维护约定

1. 改 `ZLUnsupportedSettings` 的两个集合 → 跑 `_gen-settings-audit.js` 重新生成本文。
2. 接线了一个 `notWired` 项 → 从集合里删掉，并在注释里写「已接线，不要再加回：xxx → 谁实现的」。
