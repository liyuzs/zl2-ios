# 设置项审计报告

> 日期：2026-11-08
> 目的：搞清楚 115 个设置项里，哪些在 iOS 上真正生效

---

## 一、总览

ZLSettings.swift 照搬了安卓 ZL2 的全部 **115 项**设置。但 iOS 和安卓的底层能力差别很大，逐项核查结果：

| 分类 | 数量 | 占比 | 处理 |
|---|---|---|---|
| ✅ **真正生效** | 13 | 11% | 保持可用 |
| ⛔ 安卓专属能力 | 60 | 52% | 置灰 + 说明「iOS 不支持」 |
| 🔧 待接线（真 TODO） | 14 | 12% | 置灰 + 说明「尚未接入」 |
| 🎨 安卓渲染/外观 | 24 | 21% | 置灰 + 说明原因 |
| 📦 内部状态位 | 4 | 4% | 不显示在 UI |

## 三、安卓专属（60 项，iOS 永远不会有）

### 陀螺仪（7 项）
`gyroscopeControl` `gyroscopeInvertX` `gyroscopeInvertY` `gyroscopeSampleRate` `gyroscopeSensitivity` `gyroscopeSmoothing` `gyroscopeSmoothingWindow`

> iOS 游戏内没有接 CoreMotion，而且安卓的实现绑定了它的输入管线。

### 手柄（7 项）
`gamepadControl` `gamepadCameraSensitivity` `gamepadCursorSensitivity` `gamepadDeadZoneScale` `gamepadInputMode` `gamepadInputModePrompted` `gamepadMappingConfig`

> 安卓走 SDL 直通；iOS 需要另接 `GameController.framework`，是独立工程。

### 鼠标热区（8 项）
`arrowMouseHotspot` `crossHairMouseHotspot` `iBeamMouseHotspot` `linkMouseHotspot` `notAllowedMouseHotspot` `resizeAllMouseHotspot` `resizeEWMouseHotspot` `resizeNSMouseHotspot`

> 安卓用 SurfaceView 手工判定触摸落在哪个图标区域；iOS 是 UIKit 视图树，概念不通用。

### 物理键 / 输入法（4 项）
`physicalKeyImeCode` `physicalMouseMode` `sdlAutoShowIme` `imeMagnifierAutoShow`

### 悬浮菜单球（3 项）
`showMenuBall` `menuBallOpacity` `menuBallPos`

> iOS 不允许 App 创建跨应用悬浮窗。

### 启动器外观（5 项）
`launcherActionMenuSide` `launcherCustomColor` `launcherCustomPaletteStyle` `launcherDarkMode` `launcherTaskMenuExpanded`

> iOS 跟随系统外观，不做 Material3 自定义主题。

### 触控热键栏（6 项）
`hotbarDoubleClick` `hotbarHeight` `hotbarLongClick` `hotbarLongClickDelay` `hotbarRule` `hotbarWidth`

### 搜索平台（4 项）
`searchModpackPlatform` `searchModPlatform` `searchResourcePackPlatform` `searchShadersPlatform`

> iOS 版统一走 Modrinth，不做多平台切换。

### 其他触控细分（16 项）
`mouseSize` `mouseTouchBlockMode` `controlsOpacity` `cursorSensitivity` `mouseCaptureSensitivity` `mouseControlMode` `mouseLongPressDelay` `gestureControl` `gestureLongPressDelay` `gestureLongPressMouseAction` `gestureTapMouseAction` `joystickControlMode` `requestMaxRefreshRate` `showSponsorship` `hideMouse` `enableMouseClick`

## 四、待接线（14 项，值得做）

这些 iOS **应该支持**，只是核心还没接。**这是真正的待办清单**：

| key | 缺什么 |
|---|---|
| `showFPS` / `fpsDisplayMode` | 游戏内悬浮层还没接核心的 FPS 回调 |
| `showMemory` | 同上，内存占用 |
| `versionIsolation` | 版本隔离（现在所有版本共用一个 `.minecraft`） |
| `controlLayout` | 编辑器改了布局，运行时还没读取 |
| `enableTerracotta` / `enableTerracottaNodes` / `terracottaNodes` | Terracotta 联机需 Network Extension |
| `currentAccount` / `currentGamePathId` | 账号与游戏目录的桥接 |
| `editorEnableWidgetSnap` / `editorSnapInAllLayers` / `editorWidgetSnapMode` | 编辑器吸附功能 |
| `finishedGame` | 完成标记 |

**优先级建议**：
1. `showFPS` / `showMemory` —— 玩家最关心，工作量小
2. `versionIsolation` —— 影响多版本共存
3. `controlLayout` —— 编辑器成果要能落地
4. 其余视情况

## 五、安卓渲染相关（14 项，iOS 不适用）

`sfpewPluginLayer` `sfpewRelaxedContext` `vulkanDriver` `graphicsApi` `gameFullScreen` `sustainedPerformance` `zinkPreferSystemDriver` `vsyncInZink` `dumpShaders` `skipGameIntegrityCheck` `versionCustomInfo` `nativeLibPlugins` `logBufferFlushInterval` `assetPlatformSource`

> iOS 的图形栈是 Metal + MoltenVK，安卓是 Vulkan 驱动 + Turnip/Zink。这些参数在 iOS 上没有对应物。

## 七、UI 表现

被标记的项在设置页里：

- **置灰**（opacity 0.45）
- **点击被拦截**，弹出提示说明原因
- **下方显示小字**：如「iOS 不支持此能力」「尚未接入，暂时无效」

代码位置：`SettingsScreen.swift` 的 `ZLUnsupportedSettings` 枚举 + `rowView` 的 disabled 分支。

---

## 八、结论

**iOS 版不是「安卓版阉割」，而是「安卓版的 11% 可用 + 52% 根本不存在 + 12% 待开发 + 25% 平台无关」**。

把不支持的项明确标出来，比让用户瞎调要诚实得多。
