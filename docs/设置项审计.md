## 一、总览

| 分类 | 数量 | 占比 | UI 处理 |
|---|---|---|---|
| ✅ **可改且生效** | 54 | 47% | 正常可用 |
| ⛔ 安卓专属（iOS 无对应能力） | 57 | 50% | 置灰 + 说明「iOS 不支持」 |

判定方式：不在上述两个集合里的，就是可用的。

## 三、待接线（4 项，真 TODO）

这些 iOS **应该支持**，只是还没接：

| key | 缺什么 |
|---|---|
| `enableTerracotta` / `enableTerracottaNodes` / `terracottaNodes` | Terracotta 远程联机需要 Network Extension（付费开发者账号） |
| `versionIsolation` | **核心不支持**：`JavaLauncher.m` 自己拼游戏目录，忽略 `GAME_DIR` 环境变量；而把 gameDir 指到 `versions/<id>` 又会让它找不到版本 JSON。所以隔离做不到，UI 已如实标注 |

> `versionIsolation` 严格说不算"待接线"，是"核心侧改不动"。保留在 `notWired` 里是为了让 UI 继续置灰。
