# 任务书：iOS 自签环境部署（给电脑端 AI 执行）

> 你是运行在 Windows 上的助手。用户有一台 iPhone 14（iOS 26.5），要装一个未签名的 IPA。
> 请按下面顺序执行，每步都有验证方式，失败就停下报告。

---

## 任务目标

在 Windows 上完成 **iLoader + SideStore** 部署：
1. 装好 iTunes（提供 iPhone 驱动）
2. 装好 iLoader
3. 下载目标 IPA
4. 生成配对文件
5. 把 SideStore 装到 iPhone

完成后手机会自己完成剩下的（装 LocalDevVPN、装 IPA、开 JIT）。

---

## 环境检查（先做）

```powershell
# 系统
Get-ComputerInfo | Select-Object OsName, OsVersion, OsArchitecture

# 是否管理员
([Security.Principal.WindowsPrincipal][Security.Principal.WindowsIdentity]::GetCurrent()).IsInRole([Security.Principal.WindowsBuiltInRole]::Administrator)

# 是否已装 iTunes
Get-Package -Name "*iTunes*" -ErrorAction SilentlyContinue

# 是否已连 iPhone
Get-PnpDevice -Class USB -ErrorAction SilentlyContinue | Where-Object FriendlyName -like "*Apple*"
```

**判断**：
- 非管理员 → 用管理员 PowerShell 重开
- 没 iPhone → 让用户插线并在手机上点「信任此电脑」

---

## 步骤 1：安装 iTunes

```powershell
winget install --id Apple.iTunes -e --accept-package-agreements --accept-source-agreements
```

**验证**：
```powershell
Get-Service "Apple Mobile Device Service" | Select-Object Status
# 应该能看到服务存在
```

装完后**启动一次 iTunes**，确认界面里能看到连接的 iPhone。

---

## 步骤 2：下载安装 iLoader

官方仓库：https://github.com/nab138/iloader

```powershell
$msi = "$env:TEMP\iloader.msi"
$url = "https://github.com/nab138/iloader/releases/latest/download/iloader-windows-x64.msi"
[Net.ServicePointManager]::SecurityProtocol = [Net.SecurityProtocolType]::Tls12
Invoke-WebRequest -Uri $url -OutFile $msi -UseBasicParsing
Get-Item $msi | Select-Object Length   # 应该 > 1MB

Start-Process msiexec.exe -ArgumentList "/i `"$msi`" /qb" -Wait
```

**验证**：
```powershell
Get-ChildItem "C:\Program Files\iloader","C:\Program Files (x86)\iloader" -ErrorAction SilentlyContinue
```

---

## 步骤 3：下载目标 IPA

**公开直链，无需登录**：

```
https://github.com/liyuzs/zl2-ios/releases/download/build-67/ZL2.ipa
```

```powershell
$ipa = "$env:USERPROFILE\Desktop\ZL2.ipa"
Invoke-WebRequest -Uri "https://github.com/liyuzs/zl2-ios/releases/download/build-67/ZL2.ipa" -OutFile $ipa -UseBasicParsing
Get-Item $ipa | Select-Object Name, @{N='MB';E={[math]::Round($_.Length/1MB,2)}}
```

**验证**：大小应该约 **51.77 MB**。小于 40MB 说明下载不完整，重下。

---

## 步骤 4：生成配对文件（GUI 操作）

```powershell
Start-Process "C:\Program Files\iloader\iloader.exe"
```

在 iLoader 界面里：
1. 确认左侧/顶部能识别到 **iPhone 14**
2. 找到 **Manage Pairing File**（或 Pairing / 配对文件）
3. 点 **Place** 或 **Generate**
4. 等待成功提示

**验证**：
```powershell
Get-ChildItem "$env:APPDATA","$env:LOCALAPPDATA" -Recurse -Filter "*pairing*" -ErrorAction SilentlyContinue | Select-Object FullName, Length
```

---

## 步骤 5：安装 SideStore 到手机（GUI 操作）

在 iLoader 界面里：
1. 找到 **Install SideStore**
2. 输入用户的 **Apple ID**（提醒：用备用账号，不用主号）
3. 输入密码（走苹果官方登录页）
4. 等待安装完成
5. 提示成功后，让用户在手机上操作：
   - 设置 → 通用 → VPN与设备管理
   - 找到该开发者 → 信任

**验证**：
```powershell
Get-PnpDevice -Class USB | Where-Object FriendlyName -like "*Apple*" | Select Status
```

手机上应该能看到 SideStore 图标。

---

## 完成后的交接

告诉用户手机上的后续步骤：
1. 美区 Apple ID 装 **LocalDevVPN** → 打开点 Connect
2. 打开 **SideStore** → 登录同一 Apple ID → 点 **7 DAYS** 完成初始化
3. SideStore → **+** → 选 `ZL2.ipa`（在桌面）
4. 装 **StikDebug**（https://stikdebug.xyz/）→ 对 ZL2 点 **Enable JIT**
5. 打开 ZL2 → 下载版本 → 启动

## 故障处理

| 现象 | 处理 |
|---|---|
| `winget` 找不到 iTunes | 去 Microsoft Store 手动搜索安装 |
| 下载 iLoader 403/404 | 换 portable 版：`iloader-windows-x64.exe` |
| iLoader 找不到设备 | 重启 `Apple Mobile Device Service`；换 USB 口；确认手机已信任电脑 |
| 配对文件生成失败 | 换 `idevice_pair` 工具（https://onmyodev.com/2026/10/idevice-pair/） |
| SideStore 安装失败 | 确认 Apple ID 能正常登录 appleid.apple.com；换网络 |
| IPA 大小不对 | 重新下载，直链见步骤 3 |

## 重要提醒

1. **这是从未真机验证过的 App** —— 装上去可能崩溃，属正常，把错误反馈回去
2. **iOS 26.5 的 StikDebug 没实测** —— 官方只写到 26.0+
3. **免费证书 7 天有效** —— 之后要 Refresh All
4. **不要让用户输主 Apple ID 密码给自己不信任的工具** —— iLoader 走的是苹果官方登录页，但账号风险自担
