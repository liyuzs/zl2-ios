# 周末操作手册：从 Windows 编译出 iPhone 版 ZL2 界面

> 全程只需要 **Windows + 浏览器**，不需要 Mac。
> 编译在 GitHub 的服务器上完成，你只负责上传、点按钮、下载。

---

## 0. 先理解三个概念（30 秒）

| 名词 | 是什么 |
|---|---|
| **Actions** | GitHub 免费提供的云端电脑，可以在 macOS 机器上编译 iOS App |
| **Artifact** | 编译产物，编译完在网页上下载，就是一个 zip |
| **IPA** | iPhone 的应用包，相当于安卓的 APK |

**结果会是什么**：一个能装进 iPhone 的 App，**界面完成度约 95%**，但**还不能启动游戏**（启动核心没接）。这一版是为了先看到界面像不像。

---

## 1. 注册 GitHub（10 分钟）

1. 浏览器打开 https://github.com ，点右上角 **Sign up**
2. 邮箱、密码、用户名（用户名会出现在链接里，随便起）
3. 验证邮箱（收邮件点链接，可能在垃圾箱）
4. 登录后点右上角头像 → **Settings**，确认是登录状态

> 国内网络访问 github.com 可能较慢，多刷新几次；实在打不开，用手机热点试试。

---

## 2. 创建仓库并上传项目（15 分钟）

### 2.1 新建仓库

1. 右上角 **+** → **New repository**
2. **Repository name** 填 `zl2-ios`（或任意）
3. 选 **Private**（私有，别人看不到）或 Public 都行
4. **不要**勾 "Add a README file"
5. 点 **Create repository**

### 2.2 上传文件（用网页，不装 Git）

创建完会看到空仓库页面，点 **uploading an existing file** 链接（或 `Add file` → `Upload files`）。

**关键：要保留目录结构！**

把 `ios-zl2-周末版.tar.gz` 解压后，得到的目录里应该有：

```
.github/workflows/build.yml   ← CI 配置（必须有，且路径不能变）
src/                          ← 界面代码
  Theme.swift
  HomeScreen.swift
  SettingsScreen.swift
  DownloadScreen.swift
  AccountScreen.swift
  ModsScreen.swift
  LaunchScreen.swift
  ZL2App.swift
  Assets.xcassets/
  Info.plist  ← 如果存在就传，不存在也没关系
project.yml
README.md
```

**上传方法**：网页的拖拽上传**支持拖文件夹**。把解压后的整个文件夹拖进网页即可。
如果拖文件夹不行，就在本地压缩成 zip 后……**不行，GitHub 网页不支持上传 zip 后自动解压**。

**备选方案（推荐）**：装一个 GitHub Desktop（Windows 版），用它把文件夹 commit + push，目录结构最稳：
1. 下载 https://desktop.github.com
2. 登录 → File → Add local repository → 选择解压出来的文件夹
3. 填一个提交说明 → **Commit to main** → **Push origin**

### 2.3 确认结构

上传完在仓库首页看一眼：应该能直接看到 `.github`、`src`、`project.yml` 这几个条目。
如果 `src` 里的文件全散在根目录、`.github` 不见了，说明拖拽时结构丢了，删掉重传。

---

## 3. 编译（5 分钟 + 等待）

1. 仓库顶部点 **Actions** 标签
2. 第一次会提示 "Workflows aren't being run on this repository" → 点 **I understand my workflows, go ahead and enable them**
3. 左侧选 **iOS Build**
4. 右侧点 **Run workflow** → 分支选 `main` → 绿色 **Run workflow** 按钮
5. 等 5–15 分钟（第一次装 XcodeGen 会慢些）

### 怎么知道成功了

- 状态图标变 **绿色 ✓**
- 点进去看每一步；失败的话哪一步是红叉

### 下载产物

编译成功的运行页面底部有 **Artifacts** 区域，下载 `ZL2-build.zip`。
解压后得到：
- `ZL2.ipa` —— 真机包（未签名）
- `ZL2-simulator.zip` —— 模拟器包（只能看界面，装不了手机）

> **产物只保留 90 天**，别拖太久。

---

## 4. 装到朋友的 iPhone

### 前提：查 iOS 版本

设置 → 通用 → 关于本机 → 看「版本」。

| iOS 版本 | 方式 |
|---|---|
| ≤ 17.0 | **TrollStore**（推荐，永久签名，不用重签） |
| 17.1 及以上 | **AltStore / SideStore**（每 7 天要重签一次，要电脑配合） |

### 方式 A：TrollStore（iOS ≤ 17.0）

1. 朋友的手机先装好 TrollStore（怎么装取决于版本，网上有教程）
2. 把 `ZL2.ipa` 发过去（微信/QQ 传文件，或存到网盘）
3. 用 **TrollStore 打开这个 ipa** → 安装
4. 回桌面看到图标，点开就是界面

### 方式 B：AltStore（17.1 以上）

1. 朋友电脑装 AltServer（Windows 版），手机装 AltStore
2. 手机和电脑连同一 WiFi，AltStore 里点 **+**，选 `ZL2.ipa`
3. 用朋友的 Apple ID 签名（免费账号 7 天有效期）
4. 到期后重复第 2 步续签

> **注意**：iOS 17/18 上这类 App 需要开 JIT 才能流畅运行，AltStore 有说明。**这一版只是界面**，就算 JIT 没开也能看到界面。

## 5. 报错排查表

| 现象 | 原因 | 解决 |
|---|---|---|
| Actions 页面看不到 workflow | `.github/workflows/build.yml` 路径不对 | 确认目录名是 `.github`（前面有个点），且 build.yml 在 `workflows` 里 |
| 报 `xcodegen: command not found` | brew 安装失败 | 重跑一次；或看日志里 brew 的报错 |
| 报 `找不到 project.yml` | 上传时结构丢了 | 重新上传，确保 `project.yml` 在仓库根目录 |
| 报 `scheme ZL2iOS not found` | 工程生成失败 | 看 **Generate Xcode project** 那一步的日志 |
| 编译报 `Cannot find 'XXX' in scope` | 某个 Swift 文件没传上去 | 对照上面的清单检查 `src/` 是否缺文件 |
| 报签名相关错误 | 配置问题 | 确认 `CODE_SIGNING_ALLOWED=NO` 没被改掉 |
| Artifacts 里没有 ZL2.ipa | 打包步骤失败 | 看 **Package unsigned IPA** 那一步日志 |
| 装上后闪退 | 签名无效 / 设备不兼容 | TrollStore 重装；AltStore 重新签 |
| 界面是白屏 | 入口有问题 | 检查是否有两个 `@main`（Xcode 自动生成的没删干净） |

## 6. 后续：怎么让它真能玩游戏

这一版**只有界面**。要真正启动 Minecraft，需要把 **Amethyst-iOS** 的启动核心接进来：

1. Amethyst 源码：https://github.com/AngelAuraMC/Amethyst-iOS
2. 做法：把它作为子项目或 framework 引入，`LaunchScreen` 里的模拟进度改成调用它的 `JavaLauncher`
3. 这是整个项目 90% 的工作量，不是一两个晚上能完成的
