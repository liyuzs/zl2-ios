## 关键实现细节

### 运行时路径（照搬 Amethyst）
```
ZL2.app/
  Frameworks/                              ← dylib 与 framework
  java_runtimes/java-17-openjdk/lib/libjli.dylib
  ZL2                                      ← 主可执行文件
```

### 偏好配置（CoreBridge.bootstrap 写入）
```swift
setenv("AME_HOME", documentsPath, 1)
setenv("GAME_DIR", documentsPath, 1)
loadPreferences(false)
setPrefObject("java.java_homes", [
    "0": ["1_17_newer": "17", "1_16_5_older": "8", "execute_jar": "17"],
    "17": "internal",   // internal = 用 bundle 内 java_runtimes
    "8":  "internal"
])
```

### 启动流程
1. `LaunchScreen` 出现 → 自检（核心是否链接、JRE 是否就位）
2. 点「尝试启动」→ `CoreBridge.bootstrap()` → `launchJVM(nil, target, w, h, 17)`
3. `launchJVM` 内部：读偏好 → 找 `javaHome` → `dlopen(libjli.dylib)` → `JLI_Launch`
