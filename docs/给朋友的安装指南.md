## 一、这是什么

**CraftLauncher** —— 一个能在 iPhone / iPad 上跑《我的世界》Java 版（电脑版）的启动器。

它是把安卓的 **Zalith Launcher 2** 的界面和功能，用 SwiftUI 重画成 iOS 版的。

| 属性 | 值 |
|---|---|
| 应用名 | CraftLauncher |
| 包名 | `com.liyuzs.craftlauncher` |
| 版本 | 源码是 **1.0.0 (build 1)**；包里的 `ZL2.ipa` 是旧包 build-235，装上去会显示 0.1.0 |
| 最低系统 | **iOS 16.0** |
| 设备 | iPhone / iPad |
| 方向 | **iPhone 竖屏**（启动器）/ iPad 横屏 / 游戏内横屏 |
| 签名 | **未签名**（必须自己签） |

## 二、包里装了什么（技术细节）

全部 980 个文件，确认完整：

```
Payload/ZL2.app/
├── ZL2                      13.9 MB  主程序
├── Info.plist               1.8 KB   配置
├── Assets.car               61 KB    图标资源
├── UniversalJIT26.js        9.5 KB    JIT 启用脚本（关键）
├── UniversalJIT26Extension.js 0.8 KB  JIT 扩展
├── Frameworks/              35 项
│   ├── liblwjgl.dylib               ← 图形库（OpenGL 转接）
│   ├── libMoltenVK.dylib            ← Vulkan 转 Metal
│   ├── libgl4es_114.dylib           ← OpenGL 兼容层
│   ├── libopenal.dylib              ← 声音
│   ├── libEGL.framework / libGLESv2.framework
│   ├── AltKit.framework / CAltKit.framework   ← JIT 授权
│   └── libAFNetworking / libawt_xawt / ...
└── java_runtimes/           928 项 · 三套 JRE
    ├── java-17-openjdk      305 文件  → MC 1.17 ~ 1.20.4
    ├── java-21-openjdk      308 文件  → MC 1.20.5 ~ 1.21.x
    └── java-25-openjdk      314 文件  → MC 26+
```

**结论：运行时、图形库、JIT 脚本、三套 Java 全都在里面，不用额外下载。**

## 三、能干什么 / 不能干什么

### ✅ 有把握能用

| 功能 | 说明 |
|---|---|
| 下载游戏版本 | 直连 Mojang 官方源 |
| 装 Fabric / Quilt | 支持（Forge 不支持，见下） |
| 管理模组 | 扫描 mods 目录、解析 jar |
| 管理存档 | 解析 level.dat |
| 资源包 / 光影 | 支持 |
| 服务器列表 | 真实 ping |
| 微软账号登录 | 设备码流程 |
| 主题换肤 | 490 个色值 |

### ⚠️ 没在真机上验证过

**这是最需要说清楚的一点。**

整套流程**从未在任何 iPhone 上跑通过**：

| 项目 | 风险 |
|---|---|
| 游戏能否启动 | 未知。JRE + JIT + 图形桥三者配合没实测过 |
| 帧数 | 估计 25-40 FPS（原版 1.20），取决于 JIT 是否成功 |
| 联机 | 未验证 |

### ❌ 已知不行

| 功能 | 原因 |
|---|---|
| **Forge / NeoForge** | iOS 禁止 fork 子进程，装不了 installer.jar |
| **远程 P2P 联机** | 需要 Network Extension + 付费开发者账号 |
| **上架 App Store** | 苹果不允许这类应用 |
| **MC 1.11 及更早** | 需要 Java 8，包里只带 17 / 21 / 25 |
| **从别的 App 直接分享文件进来** | 没用 `CFBundleDocumentTypes`。**能用的替代**：用「文件」App 把文件拖进 CraftLauncher 的 Documents 文件夹 |
| **外置认证（皮肤站）不是正版身份** | 会验密码、**皮肤也会显示**，但游戏内是**离线身份** —— 进不了需要正版验证的服务器 |
| **同一实例里所有版本共用 mods** | 「版本隔离」这个功能**已置灰** —— 核心启动时自己拼游戏目录、忽略我们设的路径。想把不同版本的模组分开，只能建两个**实例**（设置 → 游戏目录）|
| **微软账号过一段时间要重新登录** | token 不自动续期（约 1 小时后失效）。掉了就再登一次，存档和版本都不受影响 |
| **OptiFine 装不了** | 它是 Forge 系（要改 jar），而 iOS 不支持 Forge。想要光影请用 **Iris + Sodium**（App 里能直接装）|

> **第211轮补的后三条**：这三条原来只写在 `项目状态-当前.md` 和 `从这里开始.md` 里，
> 这份安装指南漏了。而其中**"外置认证是离线身份"和"分享进来不可用"最容易让朋友误判** ——
> 他会以为登录了就能进正版服，或者以为"用其他应用打开"应该有 CraftLauncher。

## 四、怎么装（三条路，按推荐排序）

### 路线 A：TrollStore（最省事，但看系统版本）

**适用**：iOS **14.0 – 17.0**（部分版本到 17.0.1）

TrollStore 能**永久签名**，装一次以后不用管，还能自动开 JIT——这对这个 App 特别重要。

1. 看你的 iOS 版本：**设置 → 通用 → 关于本机**
2. 打开 https://ios.cfw.guide/installing-trollstore/ 对照是否支持
3. 支持的话，装 TrollStore，然后把 `ZL2.ipa` 分享给它安装
4. 完成，不会过期

### 路线 B：SideStore（7 天续签，但苹果 17+ 也能用）

**适用**：iOS 16+ 全部

需要一台电脑（Windows 或 Mac）做一次性引导。

1. **电脑**：装 iTunes（**从 Microsoft Store 装**，官网的 EXE 版不带驱动）
2. **电脑**：装 iLoader → https://iloader.app/
3. 数据线连 iPhone，手机点「信任此电脑」
4. iLoader → Manage Pairing File → Place（生成配对文件）
5. iLoader → 装 SideStore → 输入 Apple ID（**建议用小号**）
6. 手机上：设置 → 通用 → VPN与设备管理 → 信任开发者
7. 手机装 **LocalDevVPN**（需要美区 Apple ID，App Store 免费）
8. 打开 LocalDevVPN → Connect
9. SideStore → My Apps → 右上角 + → 选 `ZL2.ipa`
10. 装好后**每 7 天**要在这个界面点一次 Refresh（LocalDevVPN 要连着）

### 路线 C：Sideloadly（一次性，但也要 7 天续签）

最简单粗暴，适合只试一次。

1. 电脑装 Sideloadly → https://sideloadly.io/
2. 电脑装 iTunes（带驱动）
3. 数据线连 iPhone，输入 Apple ID
4. 把 `ZL2.ipa` 拖进去，点 Start
5. 手机会弹「信任开发者」，去设置里信任

## 五、装完之后第一件事：开 JIT

**没开 JIT，游戏基本跑不起来。**

iOS 默认禁止 App 动态生成代码，而 Java 虚拟机必须靠这个才能跑。

### 方法：StikDebug

1. 用 SideStore 装 **StikDebug**（官网 https://stikdebug.xyz/ 有 IPA）
2. 打开 StikDebug → 找到 CraftLauncher → 点 **Enable JIT**
3. 看到成功提示

> TrollStore 用户通常**自动就有 JIT**，不用这一步。

## 六、然后开玩

1. 打开 CraftLauncher
2. 到「下载」页 → 选一个 MC 版本 → 下载（比如 1.20.1 + Fabric）
3. 回首页 → 点启动
4. 首次启动会比较慢（要解压资源）

## 七、常见报错对照表

| 现象 | 原因 | 怎么办 |
|---|---|---|
| 装不上，报 `missing bundle executable` | IPA 下载不完整 | 重新下载。**判断标准：小于 100 MB 就说明 JRE 没打进去**（完整包约 130 MB） |
| App 打开就闪退 | dylib 没签全 | SideStore 长按 → Refresh；还不行就用 Sideloadly 重新签 |
| 卡在黑屏 / 一直转圈 | JIT 没开 | 确认 StikDebug 显示已启用 |
| 启动游戏后退出 | 没下载完资源 / Java 版本不匹配 | 重新下载该版本；换 1.20.1 试试 |
| 7 天后打不开 | 免费签名过期 | SideStore → Refresh All |
| 提示「不受信任的开发者」 | 没信任证书 | 设置 → 通用 → VPN与设备管理 → 信任 |
| Forge 装不上 | **iOS 限制，装不了** | 改用 Fabric |

## 八、风险提示（务必看）

1. **这是未验证的软件** —— 从没在真机上跑通过，第一次失败是正常的
2. **不要用主 Apple ID** —— 用备用账号，避免账号被风控
3. **收费的签名服务别用** —— 那些用企业证书的，这个 App 需要特殊权限（`get-task-allow`），装上也跑不了
4. **免费签名的 7 天限制** —— 除非用 TrollStore
