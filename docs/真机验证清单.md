# ZL2-iOS 真机验证清单

> 装好 App 之后，按这个顺序点。每步记下结果（正常 / 报错 / 闪退）

---

## 第 0 步：能不能装、能不能开

- [ ] IPA 用 SideStore / Sideloadly 签名成功
- [ ] 桌面上出现 ZL2 图标
- [ ] 点开 App —— **能看到界面**（不是白屏 / 秒退）

**如果秒退**：记下闪退前有没有看到启动画面，这就是唯一线索。

---

## 第 1 步：界面能不能用

- [ ] 首页显示版本面板（皮肤、名字、启动游戏按钮）
- [ ] 右上角图标能点（联机 / 下载 / 设置）
- [ ] 点「版本列表」能看到列表
- [ ] 点「下载」能进下载页
- [ ] 点「设置」能进设置页，左侧分类能切

**如果某页白屏**：那是那个页面的代码有问题，告诉我哪一页。

---

## 第 2 步：下载一个游戏版本（最关键）

- [ ] 下载页 → 游戏 → 选一个版本（建议 1.20.1 原版）
- [ ] 点「安装」/「下载」按钮
- [ ] 看进度条是否在动（不是卡 0%）

**正常**：进度条从 0% 涨到 100%，分阶段（元数据 / jar / 依赖库 / 资源）
**异常**：
- 卡 0% 不动 → 网络或 API 问题
- 报错弹窗 → 把错误文字告诉我
- 涨到一半停 → 看是哪一阶段

**下载完检查**：进 App 的「文件管理」，看有没有 `instances/default/.minecraft/versions/1.20.1/1.20.1.jar`

---

## 第 3 步：启动游戏（最可能出问题的一步）

- [ ] 回首页，选中刚下载的版本
- [ ] 点「启动游戏」
- [ ] 看屏幕上的日志（我做了实时日志显示）

**正常**：日志滚动，出现 Minecraft 窗口
**异常（大概率）**：
- 「找不到内置 JRE」→ JRE 没打包进 IPA
- 「JVM 启动失败」→ JIT 脚本或内存问题
- 闪退 → 记下日志最后几行

**日志在哪**：App 的 Documents 目录下 `ame.log`

---

## 第 4 步：如果游戏能起来

- [ ] 能进主菜单
- [ ] 能创建世界
- [ ] 能进世界

**然后测键盘**：
- [ ] 游戏里有操作按钮（我做的覆盖层）
- [ ] 能移动、能跳

---

## 出问题怎么报

把这三样发我：
1. **哪一步**出的问题
2. **屏幕上看到什么**（报错文字 / 黑屏 / 闪退）
3. **日志内容**（如果有）

有这三样我就能定位。
