# 真机验证清单

> 给朋友用。照着做，每步记录结果，出问题就复制「环境诊断」的报告。
> 最后更新：2026-11-08

---

## 零、开始之前

这个 App **从没在任何 iPhone 上跑通过**。

所以第一次失败是**预期之内**的，不是你的问题。这份清单的目的就是让你能准确告诉我「卡在哪一步」。

### ⚠️ 已知的必然失败点：启动游戏那一步

> 2026-11-08 查出：这个 App 缺了「Java 侧启动器」这一整块组件（三个 jar）。
> 详情见 [缺失组件-Java启动器jar](缺失组件-Java启动器jar.md)。
>
> **所以「启动游戏」这一步一定失败，而且失败很快** ——
> JVM 连启动都没完成，不会出现 Minecraft 窗口。
>
> 如果报错里出现下面任意一句，就是这个问题，**不用怀疑是操作或设备的问题**：
>
> - `Error opening zip file or JAR manifest missing`
> - `ClassNotFoundException: net.kdt.pojavlaunch.PojavLauncher`
> - 或者「启动失败」但日志里几乎没内容
>
> 遇到这种情况，记录下来就行，**后面的步骤可以跳过**。
> 这个组件的补法在写在上面那份文档里。

**每做完一步，记一下结果**（成功 / 失败 / 看到的报错原文）。

## 二、安装（选一条路）

### 路线 A：TrollStore（iOS 14 – 17.0）

最省事，装一次永久可用，还自动开 JIT。

1. 对照 https://ios.cfw.guide/installing-trollstore/ 确认你的系统支持
2. 装好 TrollStore
3. 把 `ZL2.ipa` 分享给它安装

**结果记录**：☐ 成功　☐ 失败（报错：________）

### 路线 B：SideStore（iOS 16+）

1. 电脑装 iTunes（**必须从 Microsoft Store 装**，官网 EXE 版不带驱动）
2. 电脑装 iLoader → https://iloader.app/
3. 数据线连 iPhone → 手机点「信任此电脑」
4. iLoader → Manage Pairing File → Place
5. iLoader → 装 SideStore → 输入 Apple ID（**用小号**）
6. 手机：设置 → 通用 → VPN与设备管理 → 信任
7. 手机装 LocalDevVPN（需美区 ID）→ Connect
8. SideStore → My Apps → + → 选 `ZL2.ipa`

**结果记录**：☐ 成功　☐ 失败（报错：________）

### 路线 C：Sideloadly（最简单，7 天续签）

1. 电脑装 https://sideloadly.io/ 和 iTunes
2. 连手机，输入 Apple ID
3. 拖入 `ZL2.ipa`，点 Start

**结果记录**：☐ 成功　☐ 失败（报错：________）

## 十、把日志弄出来（出任何问题时做这个）

**这一步比任何描述都有用。** 有日志我能直接定位，没日志只能猜。

### 方法一：App 内一键打包（推荐，最省事）

1. 打开 App → 设置 → 左侧最下面 **环境诊断**
2. 点 **「打包日志分享」**（在「复制诊断报告」下面）
3. 弹出系统分享 → 直接发给我

这个包里有：诊断报告、核心日志 `ame.log`、游戏日志 `latest.log`、
最近两个崩溃报告、以及一份目录清单。
**一个文件就能定位问题**，比截图和手打描述有用得多。

### 方法二：手动取 ame.log（打包按钮不可用时）

1. 打开系统「文件」App
2. 进 **我的 iPhone** → **CraftLauncher**
3. 里面有个 **ame.log**
4. 长按 → 共享 → 发给我

> 日志是**追加**写入的（超过 2 MB 才会清空重来），所以旧内容也在。
> 重点是日志**末尾那一段**——那是最近一次启动的记录。
> 出问题后如果重启过 App，末尾就会变成新的启动记录，原来的可能被推上去，
> 所以尽量**先导日志再重启**。
### 日志里该看什么

打开日志搜这几句，命中哪句就说明是哪一层的问题：

| 搜这句 | 说明什么 |
|---|---|
| `Could not open` + `controlmap/default.json` | 默认控制布局没生成（进游戏会没有按钮） |
| `libs/patchjna_agent.jar 不存在，跳过` | **正常**，这是预期内的提示，不用管 |
| `cacio 没有 CTCClipboard 类` | **正常**，剪贴板功能不可用，但不影响启动 |
| `Error opening zip file` | jar 没打进包里（IPA 打包问题） |
| `ClassNotFoundException` + `PojavLauncher` | 同上，`libs/launcher.jar` 缺失 |
| `UnsatisfiedLinkError` | Java 调了一个 ObjC 没实现的 native 方法 —— **把整行发我**，我要看方法名 |
| `NoSuchMethodError` / `NoClassDefFoundError` | jar 之间版本不配套 |
| `渲染器 ... 不在包内，回落到` | 渲染器选了一个包里没有的，已自动回落 |
| `渲染器 ... 不可用，已改为` | 同上，配置文件里的旧值被纠正了 |
| `默认控制布局已就位` | **正常**，说明布局生成成功 |
| `找不到内置 JRE` / `需要 Java X，但包里只有` | JRE 版本对不上 |
| `JIT 未启用` | 没开 JIT，游戏会很卡 |

### 如果 App 直接闪退、来不及导日志

1. 设置 → 隐私与安全性 → 分析与改进 → **分析数据**
2. 找以 `CraftLauncher-` 或 `ZL2-` 开头的
3. 最新那个发我

## 附：常见问题速查

| 现象 | 可能原因 | 怎么办 |
|---|---|---|
| 装不上，报 `missing bundle executable` | IPA 不完整 | 重新下载，确认大小 **132 MB** |
| 打开就闪退 | JIT 没开 / dylib 没签全 | 开 JIT；SideStore 里长按 Refresh |
| 卡在黑屏 | JIT 没生效 | 重开 StikDebug，确认 LocalDevVPN 连着 |
| 下载卡在某个百分比 | 网络问题 | 换 WiFi，或设置里换下载源 |
| 启动后立刻退出 | Java 版本不对 | 环境诊断里看 JRE 是否齐全 |
| 7 天后打不开 | 免费签名过期 | SideStore → Refresh All |
