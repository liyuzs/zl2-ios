## 已知限制（非 bug）

| 项目 | 说明 |
|---|---|
| Forge / NeoForge | iOS 不能跑 `installer.jar`，只能用 Fabric / Quilt |
| 远程联机 | 需要 Network Extension + 付费开发者账号，EasyTier 内核未接入 |
| 版本隔离 | 设置项存在但未实现（所有版本共用一个 `.minecraft`） |
| 游戏内悬浮层 | 核心自带 `LauncherMenuViewController`，SwiftUI 版 `GameOverlay` 未接入 |
| 性能天花板 | iOS 的 JIT 权限比安卓严，原版 1.20 约 25-40 FPS |
